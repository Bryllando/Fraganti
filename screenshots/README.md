# Desktop and mobile evidence - OUD & AURA

Captured **16 November 2026** from the live React/Vite app using isolated fictional LocalStorage data.

**45 short PNGs:** 17 desktop images at **1280 x 900** and 28 mobile images at **375 x 900**. Each image shows one browser screen. Longer forms and wide admin tables have separate detail views so important text and actions stay readable. The previous long screenshots have been replaced.

These are native browser screenshots taken after scrolling to the relevant section. No image editing, mockup pages or custom capture styles were used. The browser used reduced motion. Mobile admin table detail views show their horizontally scrolled columns.

The purchase uses **2 x PHP 120.00 + PHP 85.50 = PHP 325.50**. These temporary prices and the order only existed in the test browser. Working browser data and bundled seed prices were preserved.

## Verification

All 45 replacement images were checked for dimensions, loaded images, labeled form inputs, page overflow and runtime errors. The [JSON report](browser-results.json) records the scroll positions, image hashes, fixture order and per-page measurements. Confirmation shows Pending; admin shows the same order as Completed. Existing item names and prices remain unchanged after a catalog edit.

The earlier automated run passed 36 data tests, 32 browser tests and the production build. Application code was unchanged during this screenshot update. Physical phones, other browser engines, screen readers, exhaustive keyboard traversal and the demo video were not verified.
